A small stack, deliberately wired.

A self-hosted control plane for models, memory, and the services that keep the house running.

Decisions

One model resident at a time

llama-swap unloads Qwen from the GPU and loads the diffusion model before ComfyUI generates, holding nothing in common between the two heavy weights. A single model stays resident because the unload-then-load protocol enforces it, not configuration, so VRAM never straddles two models at once.

Memory lives off the inference box

Mnemosyne keeps retrieval memory outside the model server, so neither prompts nor answers ride through whichever weight is currently inferring; reads and writes travel their own edges no matter which model is resident. That separation lets the Discord task read and update the same store through OpenCode while llama-swap swaps a diffusion model onto the GPU.

Nothing exposed publicly

Every external path terminates behind Tailscale, so no port or service binds to the public interface; an off-network phone still reaches Hermes only as a tailnet member. Because nothing listens externally there is no public surface to patch at midnight when the health sweep fires.
